# 🍔 Online Food Delivery System – DBMS Project

Hi! 👋

This repository contains my **Database Management System (DBMS) assignments** completed as part of my BCA (Honours) in AI & ML at Alliance University.

The project is based on an **Online Food Delivery System**, similar to apps like Swiggy and Zomato. It focuses on designing a database, creating tables, inserting data, and writing SQL queries to manage food orders.

## 📌 Project Overview

The system manages:
- 👤 Customers and their delivery addresses
- 🍽️ Restaurants and food menus
- 🛵 Delivery agents and order details
- 💳 Payments and transactions
- ⭐ Customer ratings and reviews

## 🛠️ Technologies Used

- **MySQL** – Database management
- **SQL** – Creating tables and managing data
- **ER Diagrams** – Understanding database relationships
- **Relational Database Design** – Organizing data efficiently

## 📚 Assignments Included

| Assignment | Topic |
|---|---|
| 1 | Identifying Tables for a Real-World Application |
| 2 | ER Diagram Design and Relational Schema |
| 3 | Database Design Analysis and Normalization |
| 4 | Relational Database vs. NoSQL Database |
| 5 | Database Creation and Table Implementation |
| 6 | Data Integrity Constraints |
| 7 | Sample Data Insertion |
| 8 | Basic SQL Queries and Aggregate Functions |
| 9 | Advanced SQL Queries Using Joins and Subqueries |

## 💡 What I Learned

Through these assignments, I learned how to:

- Design a database for a real-world application.
- Create tables using SQL commands.
- Use primary keys and foreign keys.
- Apply constraints to maintain accurate data.
- Insert and manage sample records.
- Write queries using `SELECT`, `WHERE`, `ORDER BY`, and `GROUP BY`.
- Use aggregate functions such as `COUNT()`, `SUM()`, and `AVG()`.
- Connect tables using `JOIN` operations.
- Use subqueries to retrieve specific information.
- Understand normalization and reduce data duplication.
